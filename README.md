# Personal Bio & Portfolio Website (`bio-page`)

A responsive, multi-page personal bio and portfolio website built with HTML5, CSS3, and JavaScript. It showcases my background, completed web and software development projects, and contact details, complete with mobile-friendly navigation, keyboard accessibility support, and a Dark Mode toggle.

## Project Structure

* `index.html` – Home page and introduction
* `about.html` – About me and background details
* `projects.html` – Portfolio project grid showcasing web development work
* `contact.html` – Centered contact card and contact form
* `style.css` – Responsive layout, Flexbox/Grid styling, and Dark Mode styles
* `script.js` – Interactive functionality
